# mtai.news

Лента новостей для Bitrix24 на инфоблоке с расширенными правами.

![Лента: категории, картинки, реакции с попапом голосовавших, просмотры и комментарии](mtai.news/docs/feed-reactions.png)

![Детальная: реакции и комментарии Живой ленты от разных пользователей](mtai.news/docs/detail-comments.png)

## Что внутри

- **Инфоблок** — стандартные тип `news` и инфоблок `news`: если они уже есть
  на портале, модуль использует их как есть (существующий инфоблок переводится
  в расширенные права `RIGHTS_MODE=E`: G1→X, G2→R), если нет — создаёт; при
  uninstall удаляется только созданное модулем. Разделы — категории новостей,
  элементы — новости. Свойства `BLOG_POST_ID`/`BLOG_COMMENTS_CNT` заводит
  штатный `bitrix:catalog.comments`.
- **Компонент `mtai.news:feed`** — лента карточек: лайки-реакции живой ленты
  (`bitrix:rating.vote` like_react), счётчик просмотров
  (`bitrix:socialnetwork.contentview.count`), число комментариев,
  фильтр по категориям, аякс-подгрузка при скролле (эндпоинт `/news/ajax.php`
  отдаёт частичный рендер шаблона `page` в JSON), восстановление позиции
  ленты при возврате по кнопке «Назад» браузера (history.state).
- **Компонент `mtai.news:detail`** — детальная новость: фиксация просмотра
  (`b_sonet_user_content_view`, уникально по пользователю), лайки, комментарии
  Живой ленты (`bitrix:catalog.comments`, шаблон `stream`). Обработчик
  `OnPostAdd` выдаёт автосозданному посту блога коды `BLOG_POST_RIGHTS`
  (по умолчанию `G2`) — без этого сотрудники не видят комментарии.

## Установка

1. Скопировать папку `mtai.news/` из репозитория в `local/modules/` портала
   (например, `git clone git@github.com:MTai88/bitrix24_news.git mtai.news`).
2. Установить модуль в админке: **Настройки → Настройки продукта → Модули →
   Новости (mtai.news) → Установить**.

Установщик сам:

- создаст (или переиспользует) тип `news` и инфоблок `news` с расширенными
  правами (`RIGHTS_MODE=E`: G1→X, G2→R);
- скопирует страницы `/news/` (лента, детальная, ajax-эндпоинт), компоненты
  `mtai.news:feed`/`mtai.news:detail` и шаблон `stream` для
  `bitrix:catalog.comments`;
- добавит правило urlrewrite `/news/{id}/ → /news/detail.php?ID={id}` и
  файловый доступ к `/news/` для группы «Все пользователи».

Контент (категории, новости, картинки, реакции) создаётся штатными средствами —
через админку инфоблока. Скрипты наполнения демо-данными в репозиторий не
входят (они специфичны для тестового стенда).

Страница ленты: `/news/`, детальная: `/news/{ID}/`. Удаление модуля убирает
страницы, компоненты и созданные им тип/инфоблок; переиспользованные (чужие)
тип и инфоблок не трогаются.
